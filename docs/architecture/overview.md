# Overview

```
CodeScanner
│
├── ScannerController
├── LangHandler
├── AreaResolver
├── ScannerBuilder
├── UIBuilder
└── StateHandler
```

## CodeScanner

Public API exposed to the user.

### ScannerController

Handles camera access and barcode detection.

### LangHandler

Provides UI texts.

### AreaResolver

Computes the scan area dimensions.

### ScannerBuilder

Builds scanner-related DOM elements.

### UIBuilder

Builds the user interface.

### StateHandler

Manages scanner states (default, success, error).
